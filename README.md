# Описание проекта

Проект представляет собой прототип шутера с минималистичным интерфейсом и визуальным оформлением: все игровые объекты представлены в виде квадратов.

При запуске игры игрок появляется на игровом поле и может перемещаться по нему и осуществлять стрельбу.

### Управление

* **WASD** — перемещение игрока;
* **ЛКМ** — стрельба.

# Список сцен

## Сцена пули — `bullet.tscn`

Сцена представляет собой игровой объект размером **16×16 пикселей**, который создаётся при активации действия `shoot`.

### Скрипт — `bullet.gd`

Скрипт отвечает за поведение пули после её создания. В частности, он определяет направление и движение пули в соответствии с направлением, в котором находится игрок.

---

## Сцена игрока — `player.tscn`

Сцена содержит игровой объект игрока и связанную с ним логику управления.

### Скрипт — `player.gd`

Скрипт реализует основные функции игрока:

* перемещение по игровому полю;
* стрельбу;
* выход из игры;
* задержку между выстрелами с помощью таймера.

Сцена игрока взаимодействует со сценой `bullet.tscn`: при активации стрельбы `player.gd` создаёт экземпляры сцены пули.

Таким образом, `player.tscn` и `bullet.tscn` находятся в отношении **siblings** на уровне взаимодействия сцен: игрок использует пулю, создавая её экземпляры, но сама пуля не является дочерним объектом игрока.

---

## Сцена игрового поля — `grass.tscn`

Сцена представляет собой основное игровое поле, на котором происходит игровой процесс.

### Скрипт — `grass.gd`

Скрипт отвечает за инициализацию игрового поля и создание экземпляра игрока при запуске игры.

`grass.tscn` выступает в качестве родительской сцены для `player.tscn`: экземпляр игрока создаётся и размещается непосредственно на игровом поле.

Таким образом, основная структура взаимодействия сцен выглядит следующим образом:

```text
grass.tscn
    │
    └── player.tscn
            │
            └── создаёт экземпляры
                bullet.tscn
```
