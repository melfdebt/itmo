# itmo
## описание проекта 
прототип шутера, с минимальным интерфейсом (все объекты представлены квадратами). игрок создается на игровом поле и имеет возможность передвигаться и стрелять.
## список всех сцен
### сцена пули (bullet.tscn)
сцена представляет собой квадрат 16х16, который создается при активации действия "shoot"
скрипт - bullet.gd, определяет направление движения пули (по направлению с игроком)
### сцена игрок (player.tscn)
скрипт  - player.gd
внутри содержит функции для перемещения, стрельбы и выхода из игры, также там реализована функция задержки стрельбы с помощью таймера. 
находится в отношениях с классом bullet (siblings), так как вызывает создание экземпляров пуль.
### сцена поля (grass.tscn)
скрипт - grass.gd
основное игровое поле, создает игрока при запуске игры. является родительским классом для класса player.
